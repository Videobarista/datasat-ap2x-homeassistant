# Brand assets

This folder is intentionally empty.

Home Assistant shows a generic icon for this integration because no brand
assets have been submitted to [home-assistant/brands](https://github.com/home-assistant/brands).
The Datasat name and logo are trademarks of Datasat Digital Entertainment / ATI
and are not redistributed here.

If you have permission to use the logo, drop `icon.png` (256x256) and
`logo.png` here and open a pull request — or submit them directly to the
brands repository under the domain `datasat_ap2x`.
